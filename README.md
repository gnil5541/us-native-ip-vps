## 原生IP、双ISP、9929，三个词各管一件事

9929 是线路，跟 IP 属性没关系。AS9929 是联通旗下的 CUII 精品网，地位大致相当于联通版的 CN2 GIA。普通美国机器回国走 163 骨干，晚高峰一堵就绕路；9929 是优先级更高的通道，回程从这条线回国再分给三网。另一条常被拿来对比的 CN2 GIA 归电信，一个联通一个电信，别混着叫。线路决定你晚上八点开网页要不要等，跟 IP 在美国哪个段没有关系。

原生 IP 说的是 IP 的注册归属信息。IP 段注册在美国本地 ISP 名下、在本地原生广播，数据库里查出来归属地就是机房所在的城市。与它相对的是广播 IP：机器在美国，IP 段其实注册在别处，靠 BGP 路由宣告成美国地址，流媒体、广告平台、Google 收录在识别时会吃亏。

双 ISP 住宅 IP 在原生之上再加一层。ASN 检测里这个 IP 同时被认成 ISP 类型和住宅宽带运营商，比单纯的原生 IP 更像一户本地家庭宽带。做 TikTok 账号、电商店铺、社媒矩阵的人看重这个，风控相对宽松。这个“相对”要理解准确：它提高的是被认成本地住宅用户的概率，平台风控名单是动态的，某个段被滥用过就会临时降级，没有哪家能保证永久解锁。

有个细节值得单独拎出来。六六云那款“美国原生IP三网CN2 GIA大带宽”的说明里，自己写着“不保证ISP属性”。想靠 IP 属性做业务，又只盯着 CN2 GIA 这四个字下单，很可能买回来一个线路很好但属性不对的机器。做账号的应该去看双 ISP 那几款。
